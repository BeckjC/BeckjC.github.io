## Design Patterns Observed

### Movement/Animation Styles:
- **Scroll-triggered** - Parallax, fade-ins, content reveals
- **Micro-interactions** - Hover states, button animations, cursor effects
- **3D/WebGL** - Three.js environments, shader effects, particle systems
- **Gradient animations** - Mesh gradients, color transitions
- **Page transitions** - Smooth routing, scene changes

### Typography Trends:
- **Large display type** - Bold headlines, statement pieces
- **Variable fonts** - Weight changes on scroll/hover
- **Monospaced accents** - Code aesthetic without being dev-only
- **Generous whitespace** - Breathing room, not cramped

### Color Approaches:
- **Duotone** - Two main colors, high contrast
- **Gradients** - Vibrant, multi-stop, animated
- **Dark mode first** - Many portfolios default dark
- **Neon accents** - Cyberpunk influence (used sparingly)

### Layout Strategies:
- **Asymmetric grids** - Broken grid, intentional irregularity
- **Full-bleed images** - Edge-to-edge, immersive
- **Sticky sections** - Content anchors while scrolling
- **Horizontal scroll** - Breaking vertical convention

## What NOT to do (Generic Template Vibes):

❌ Stock gradient backgrounds (linear blue-to-purple)  
❌ Generic "About/Work/Contact" navbar  
❌ Cookie-cutter grid layouts  
❌ Over-designed skill bar charts  
❌ Carousel sliders that auto-play  
❌ Parallax just for parallax sake  
❌ Hype language ("Rockstar developer", "Ninja designer")

## Direction for Beck's Site

**Core principle:** Clean, modern, honest - movement that serves purpose

**Design hooks to explore:**
1. **Interactive cursor** - Custom cursor that reacts to content
2. **Text animations** - Kinetic typography, not static headings
3. **Project reveals** - Smooth transitions between portfolio pieces
4. **Gradient mesh background** - Subtle, Stripe-inspired
5. **Code aesthetic** - Terminal vibes without being cliché

**Technical approach:**
- Modern CSS (grid, custom properties, animations)
- Vanilla JS or lightweight framework (no bloat)
- WebGL for one signature effect (not everything)
- Performance-first (90+ Lighthouse score)
- Progressive enhancement (works without JS)

**Content strategy:**
- **Honest bio** - No hype, actual story
- **Real projects** - Yacht AI, Zero to CEO, actual work
- **Links hub** - GitHub, LinkedIn, contact
- **Optional:** Blog integration (if keeping separate from Zero-to-CEO)
